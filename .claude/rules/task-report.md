# Rule: Gerador de Relatório de Task Obrigatório

Ao finalizar qualquer implementação de funcionalidade ou refatoração relevante:
1. Deve ser gerado um documento em `docs/tasks/YYYY-MM-DD-[feature].md`.
2. O documento deve calcular a estimativa de redução de tokens via Graphify, listar arquivos alterados, testes executados e riscos remanescentes.
