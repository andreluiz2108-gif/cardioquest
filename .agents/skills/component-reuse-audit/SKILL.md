---
name: component-reuse-audit
description: Audita a base de código em busca de componentes visuais duplicados ou oportunidades de abstração em UI.
---

## Procedimento
1. Varrer a pasta `app/` e `components/`.
2. Identificar estilos duplicados, botões com a mesma estrutura ou hooks repetidos.
3. Propor a refatoração extraindo componentes para `components/ui/`.
